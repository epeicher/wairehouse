AI Agents — demo ideas (productivity-first)

Demos for the Desktop Mode agents framework (PR #428). All six agents below are seeded and working on the demo site. Framing that sells: name the boring task → show the manual cost → drag, drop, done → show the receipt. The receipt is the differentiator: agents are real WordPress users, so every demo can close in wp-admin showing the revision or attachment authored by the agent. Drag & drop is the hook — "drop the image on the robot" reads instantly on a projector or in a 15-second clip.

The six demos

AgentRoleDropWhat happensTime-saved pitch
TLDR Editoreditorpost, page Proposes a summary; apply <ID> inserts it at the top, formatting preserved, revision attributed. 5–10 min per post to read and summarize; a 1,000-post archive is a month nobody will ever spend.
SEO Mediceditorpost, page Applies a missing excerpt, proposes three titles and a meta description. ~10 min per post for an SEO pass, done in one drop.
Comment Conciergeeditorpost Read-only triage: sentiment summary, spam/toxicity flags, paste-ready reply drafts. Safest live demo — no write tools. 30+ min/day of moderation queue becomes a 2-minute review.
Alt Text Librarianmediamedia Writes descriptive alt text to the Media Library and verifies it. Uses the new desktop-mode/update-media ability. 2–3 min per image, legally required in more and more markets, almost universally skipped; clears a 500-image backlog over coffee.
Localizerauthorpost, page Creates a "[ES] …" draft translation, markup preserved, original untouched. Uses the new draft-only desktop-mode/create-post ability (structurally cannot publish). Translation round-trips take days; a reviewable draft in seconds.

The 3-minute keynote narrative

Chain them as "the Monday morning routine":

  1. Drop a fresh draft on TLDR Editor, then SEO Medic.
  2. Drop yesterday's post on Comment Concierge.
  3. While results stream in, open Users and deliver the close over the "Agent" badges: "Everything you just watched was done by these users. They have roles, they can't log in, every edit is in the revision history — and if one misbehaves, you fire it like an employee."
  4. Roadmap tease: the hook trigger means the Concierge runs on every new comment without the drag.

Staging notes

  • Put a running stopwatch on screen — the productivity claim needs a visible clock.
  • Seed realistic prose; generated filler text produces vague summaries that undercut the TL;DR demo.
  • Drag targets are agent tiles: drag each agent on stage from Users onto the wallpaper beforehand, and give it a Drag & drop trigger.
  • Show the Tools pane once: "this checklist is the permission boundary — the agent literally cannot do anything else". Approval steps (apply <ID>) demo human-in-the-loop, not friction.
  • Dependencies: SEO Medic, Concierge, and Librarian lean on the ai/* abilities plugin.
