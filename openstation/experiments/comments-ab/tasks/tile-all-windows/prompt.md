Add a "Tile all windows" entry to the dock's System menu (the menu whose first row is "OpenStation Preferences"), placed right after "Fullscreen".

Choosing it arranges every open window on the current desktop so that together they use the available space: two windows side by side (half/half), three windows in thirds (1/3-1/3-1/3), four windows in a 2x2 square, and so on for more windows.

Follow the repository's contributor guide for the workflow. Do not start Docker or wp-env; the PHP test suite is out of scope for this task. When you are done, reply with a short summary of what you changed and which checks you ran.
